# 🌱 Plant Defender

Plant Defender is a 2D tower defense-style game developed in **Unity** using **C#**. The player must strategically defend a valuable plant from waves of enemies by placing defensive units, managing resources, and surviving increasingly difficult levels.

This project was developed to demonstrate game development skills, object-oriented programming, Unity gameplay systems, and software engineering principles.

---

## 🎮 Features

- 2D tower defense gameplay
- Enemy wave system
- Plant protection mechanics
- Player health system
- Collision detection
- Object-Oriented Programming (OOP)
- Interactive user interface
- Level progression
- Game over and victory conditions
- Unity physics and animations

## 🏗 Project Architecture

The project follows a modular object-oriented design where gameplay components are separated into reusable scripts.

Key systems include:

- Player Controller
- Enemy AI
- Wave Manager
- Health System
- Collision Detection
- UI Manager
- Game Manager
- Level Management
